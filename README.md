# 📝 Lista de tarefas

Aplicação de lista de tarefas desenvolvida para praticar JavaScript
e conceitos de desenvolvimento front-end.

O projeto passou por diferentes versões durante meus estudos,
evoluindo de uma implementação inicial para uma aplicação com
persistência de dados no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- JSON

## Funcionalidades

- Adicionar tarefas
- Concluir tarefas
- Reverter tarefas concluídas
- Excluir tarefas
- Salvar tarefas no navegador
- Recuperar tarefas após recarregar a página

## Conceitos praticados

- Manipulação do DOM
- Eventos
- Arrays
- Objetos
- Funções
- LocalStorage
- JSON
- `JSON.stringify()`
- `JSON.parse()`
